# EP-001: 蔵書管理

由来: `requirements/EP-001-book-management.md`

> 蔵書モデル（書誌 / 所蔵の分離）は ADR-010。書誌・所蔵の全項目は requirements「蔵書モデル」を参照。所蔵の状態: `整理中` / `在架` / `貸出中` / `予約取置` / `配送中` / `返送中` / `紛失` / `破損` / `除籍`。

## F-01: ISBN による書誌登録

### 概要

ISBN を入力/スキャンして NDL から書誌を取得し、司書が補正して**書誌**を新規登録する。続けて所蔵登録（F-02）に進む。

### 業務ルール

- 既存の同一 ISBN がある場合は新規作成せず、その書誌の所蔵追加（F-02）へ誘導する。
- NDL 取得に失敗（不通・該当なし）した場合は手動入力にフォールバックする（→ EP-007 US-020 / ADR-003）。
- 書誌取得元は**プラガブル**（初期 NDL、将来 NACSIS-CAT / CiNii Books を会員館向けに追加。ADR-003 / EP-013）。
- ISBN は任意（ISBN 無し資料も登録可）。ISBN 有りの場合はテナント内一意。
- 書影は外部API（OpenBD / Google Books / NDL サムネ等）から取得を試み、無ければ手動アップロード（取得元・保存方式は Q-008）。

### 画面 / インターフェース

- ISBN 入力欄（バーコードスキャン対応）＋「書誌取得」操作。
- 取得結果プレビュー → 書誌フォーム（項目は requirements「蔵書モデル」の書誌欄。NDL 取得分はプリフィル）。必須: タイトル・資料種別。
- 保存後、所蔵登録（F-02）へ遷移。

### エラー条件

- ISBN 形式不正 → バリデーションエラー（業務検証は `validateParams`）。
- NDL タイムアウト / 該当なし → 手動入力へ切替（処理は止めない）。
- ISBN 重複 → 既存書誌の詳細 / 所蔵追加へ誘導。

### 由来 US

- US-001, US-020

## F-02: 所蔵追加

### 概要

書誌に対して物理的な所蔵を N 件登録する。

### 業務ルール

- 所蔵バーコードはテナント内一意。自動採番またはスキャン入力（既存バーコード流用可）。
- 必須: 所属キャンパス、配架場所（請求記号）。初期状態は `在架`。

### 画面 / インターフェース

- 所蔵追加フォーム（項目は requirements「蔵書モデル」の所蔵欄）: キャンパス / 配架場所・請求記号 / 巻次・巻号 / 貸出区分 / 受入情報（受入方法・年度・購入価格・購入先・予算区分）/ バーコード（自動採番 or 入力）/ 登録番号 / 冊数。
- 追加した所蔵の一覧表示。

### エラー条件

- バーコード重複 / キャンパス未選択 / 配架場所未入力。

### 由来 US

- US-001, US-003

## F-03: 蔵書編集

### 概要

書誌情報および所蔵（配架場所・キャンパス・貸出区分・巻次巻号・受入情報・登録番号 等）を編集する。

### 業務ルール

- ISBN 変更時は重複チェック。
- 所蔵の状態は原則イベントから導出（貸出/返却/予約/配送）。司書は例外として `紛失` / `破損` を**手動設定**できる（理由を記録。蔵書点検=EP-009・返却時の破損=EP-003 からも設定されうる）。`除籍` は F-04 経由。
- 書誌は全館共有。編集は **誰（司書アカウント・所属キャンパス）がいつ行ったかを履歴に記録**する（ADR-009）。
- 所蔵の編集は**自館分のみ**（他館の所蔵は閲覧のみ）。

### 画面 / インターフェース

- 書誌編集フォーム。所蔵一覧のインライン編集（配架場所・キャンパス・貸出区分・巻号・受入情報 等）と、状態の手動変更（`紛失` / `破損`）。

### エラー条件

- ISBN 重複 / 不正な状態遷移。

### 由来 US

- US-002

## F-04: 除籍

### 概要

所蔵を `除籍` 状態にする（物理削除しない）。誤りや発見時は復元できる。

### 業務ルール

- `貸出中` / `予約取置` / `配送中` の所蔵は除籍不可。
- 除籍は理由とともにイベントとして記録する（ADR-009）。
- 全所蔵が除籍 / 0件になった書誌はアーカイブ扱い（一覧の既定から除外、詳細は参照可）。
- **除籍の復元**: 誤除籍・除籍済みが見つかった場合は復元できる（在架等へ戻す。理由・実行者を記録）。

### 画面 / インターフェース

- 所蔵ごとの除籍操作（理由選択）＋確認。

### エラー条件

- 除籍不可状態（貸出中等）での操作 → エラー表示。

### 由来 US

- US-002

## F-05: 蔵書詳細

### 概要

書誌情報・所蔵一覧・貸出履歴を表示する。

### 業務ルール

- 在庫数 / 貸出中数を (書誌, キャンパス) 単位で集計表示する。

### 画面 / インターフェース

- 書誌情報パネル。
- 所蔵テーブル: バーコード / 登録番号 / 巻号 / キャンパス / 配架場所 / 貸出区分 / 状態。
- 貸出履歴（所蔵ごと・書誌集計）。

### 由来 US

- US-003

## F-06: 蔵書一覧・検索（管理）

### 概要

管理画面で蔵書を検索・一覧し、編集・詳細への入口とする。

### 業務ルール

- テナントscope。一覧はカーソルページング（`performance.md`）。
- 既定では除籍済み（アーカイブ）書誌を除外。フィルタで含められる。

### 画面 / インターフェース

- 検索フォーム: タイトル / 著者 / ISBN / 件名 / 分類 / 資料種別 / キャンパス / 状態。
- 結果テーブル（書誌単位、在庫数・貸出中数を集計表示）→ 行から詳細(F-05) / 編集(F-03)。

### エラー条件

- なし（該当0件は空状態表示）。

### 由来 US

- US-002, US-003

## F-07: 蔵書の一括登録（CSV 取込）

### 概要

CSV 等のファイルで複数の書誌・所蔵をまとめて登録する。導入初期の大量登録や移行前の初期投入を想定。

### 業務ルール

- 1 行 = 1 所蔵（書誌情報＋所蔵情報）。既存 ISBN は書誌を再利用し所蔵だけ追加（F-01 と同じ集約ルール）。
- ISBN があれば NDL 補完も可能（任意）。ISBN 無し行は手入力列で登録。
- 取込はプレビュー → 検証（エラー行を提示）→ 確定。エラー行はスキップまたは修正して再取込。
- 取込結果（成功 / 失敗件数）と実行者を履歴に記録（ADR-009）。

### 画面 / インターフェース

- CSV アップロード → マッピング / プレビュー → 検証結果（エラー行をハイライト）→ 取込確定。
- テンプレート CSV のダウンロード。

### エラー条件

- 形式不正・必須列欠落・バーコード重複 → 該当行をエラーとして提示（全体は止めない）。

### 由来 US

- US-001

## F-08: ラベル印刷

### 概要

所蔵に貼る ①資産バーコードラベル ②背ラベル（請求記号）を印刷する。所蔵登録（F-02）直後、または所蔵一覧 / 詳細から実行。

### 業務ルール

- 印刷内容は所蔵の **資産バーコード** と **請求記号**（別置記号＋分類番号＋著者記号＋巻冊記号）から生成。
- 複数の所蔵をまとめて一括印刷できる。
- ラベル様式（サイズ・レイアウト）は印刷設定で選択（詳細は設計フェーズ）。

### 画面 / インターフェース

- 所蔵一覧 / 詳細 / 登録直後から「ラベル印刷」→ 対象選択 → プレビュー → 出力（PDF 等）。

### エラー条件

- 請求記号が未設定の所蔵は背ラベルを生成できない（警告し、バーコードのみ印刷可）。

### 由来 US

- US-001
