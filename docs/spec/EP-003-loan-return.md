# EP-003: 貸出・返却・延滞管理

由来: `requirements/EP-003-loan-return.md`

> 状態はイベント（貸出 / 返却 / 延長 / 予約 / 督促）から導出し、参照は `current_status`（ADR-009）。貸出ルールは利用者種別ごと（EP-002 種別マスタ）。

## F-01: 貸出（スキャン）

### 概要

利用者の識別子と本のバーコードをスキャンして貸出を確定する。

### 業務ルール

- ルール判定: **貸出上限超過 / 禁帯出 / 利用者 `current_status` = 停止** → 貸出不可。
- 返却期限 = 貸出日 ＋ 種別の貸出期間（自動算出）。**長期貸出期間（対象種別は休み明け日）** と **休館日カレンダー（休館日は翌開館日へ繰り下げ）** を考慮。
- 予約取置中の所蔵は、その予約者にのみ貸出可。
- 貸出は `e_loans` に追記し、所蔵 `current_status` を貸出中に更新（同一 Tx）。

### 画面 / インターフェース

- 利用者スキャン → 利用者・利用状況表示 → 本のバーコード連続スキャン → 貸出確定（返却期限表示）。

### エラー条件

- 上限超過 / 禁帯出 / 利用者停止中 / 所蔵が貸出不可状態 → エラー表示（理由つき）。

### 由来 US

- US-007

## F-02: 返却

### 概要

本のバーコードをスキャンして返却を確定し、在庫・予約・返送を処理する。

### 業務ルール

- `e_returns` に追記（返却日・返却館）。所蔵 `current_status` を更新（同一 Tx）。
- **どのキャンパスでも返却可**。借りた館と異なれば**返送**（`current_status` = 返送中 → 元館到着で在架。拠点間は EP-005）。
- 予約待ちがあれば次の予約者へ取置（→ F-05）。
- 延滞中だった場合、返却で利用者の停止を解除。

### 画面 / インターフェース

- 本スキャン → 返却確定 → 予約取置 / 返送 の案内表示。

### エラー条件

- 貸出記録のない所蔵の返却 → 警告。

### 由来 US

- US-008

## F-03: 貸出延長

### 概要

貸出の返却期限を延長する（司書、または利用者は OPAC = EP-004）。

### 業務ルール

- **延長回数の上限内 かつ 予約者がいない** 場合のみ可。
- `e_renewals` に追記し、返却期限を更新。

### 画面 / インターフェース

- 貸出から「延長」操作 → 新返却期限表示。

### エラー条件

- 延長上限超過 / 予約者あり / 延滞中 → 不可（理由表示）。

### 由来 US

- US-013（EP-004。ルールは EP-003）

## F-04: 延滞一覧・督促

### 概要

延滞中の貸出を一覧し、督促・利用停止を行う。

### 業務ルール

- 延滞 = 貸出中かつ返却期限超過（導出 / `current_status`）。
- 督促を送り `e_reminders` に記録。延滞中の利用者は新規貸出停止（`current_status` = 停止）、返却で解除。延滞金なし。

### 画面 / インターフェース

- 延滞一覧（利用者・所蔵・延滞日数）→ 督促送信・記録。

### エラー条件

- なし（該当 0 件は空状態表示）。

### 由来 US

- US-009

## F-05: 予約の取置・引き当て

### 概要

返却された所蔵を予約待ちの先頭へ取り置く（予約の受付は OPAC = EP-004）。

### 業務ルール

- 返却（F-02）時に予約待ちがあれば、次の予約者へ取置（所蔵 `current_status` = 予約取置）。
- 取置期限 **7日**（過ぎたら次の予約者へ）。割当ロジックは Q-006（最も早く返る所蔵 / 受取館の所蔵）。

### 画面 / インターフェース

- 取置一覧（予約者・所蔵・取置期限）→ 取置・期限切れ処理。

### エラー条件

- なし。

### 由来 US

- US-011（EP-004。取置は EP-003）

## F-06: 貸出ルール・カレンダー設定

### 概要

利用者種別ごとの貸出ルール（上限・期間・延長・予約上限）と、長期貸出期間（休暇）・休館日カレンダーを設定する。

### 業務ルール

- EP-002 の利用者種別マスタ（F-08）に紐づく。値は Q-013。
- **長期貸出期間**: 期間名・適用期間・休み明け返却期限日・対象種別（学生・教員）を設定。期間内の新規貸出に適用し、対象の既存貸出も一括延長。
- **休館日カレンダー**: 休館日（定休・長期休暇・臨時）を設定。返却期限が休館日なら翌開館日へ繰り下げ（全種別）。
- いずれもテナント/キャンパス単位。変更は監査記録（誰が・いつ。ADR-009）。

### 画面 / インターフェース

- 種別ごとのルール編集（貸出上限 / 貸出期間 / 延長可否・回数 / 予約上限）。
- 長期貸出期間の登録（期間・休み明け日・対象種別）／休館日カレンダーの編集。

### エラー条件

- 不正値（負数等）。

### 由来 US

- （管理基盤。種別マスタ EP-002 F-08 と連携）

## F-07: リコール（recall）

### 概要

予約が入った貸出中の所蔵について、返却期限を繰り上げて早期返却を要請する。

### 業務ルール

- 貸出中の所蔵に予約が入ったら、返却期限を繰り上げ（リコール期限）、利用者へ督促（`e_reminders` / リコール通知）。
- 学術図書館の定番（予約者の待ち時間短縮）。

### 画面 / インターフェース

- リコール対象一覧 → リコール実行（期限繰り上げ・通知）。

### エラー条件

- なし。

### 由来 US

- US-011（EP-004 予約。呼び戻しは EP-003）

## F-08: 弁償処理

### 概要

紛失・破損の所蔵について弁償を処理する。

### 業務ルール

- 対象: `紛失` / `破損` の所蔵。弁償額＝定価ベース（定額・上限の設定可。Q-020）。
- 弁償完了で所蔵を除籍（必要なら同一書誌へ補充＝新所蔵追加）。利用者・所蔵・金額・日時を記録（ADR-009）。

### 画面 / インターフェース

- 弁償対象（紛失 / 破損）一覧 → 弁償額提示 → 弁償受領記録 → 除籍 / 補充。

### エラー条件

- 弁償額未設定。

### 由来 US

- US-009（延滞管理の周辺。紛失 / 破損対応）
