# EP-001: 蔵書管理

## 概要

司書（管理画面）が蔵書を登録・編集・除籍し、蔵書ごとの詳細を管理する。登録時は ISBN から書誌を自動取得して職員の負担を減らす。蔵書は **書誌（本の情報）と所蔵（物理的な1冊）に分離**して扱う（ADR-010）。

## 蔵書モデル（前提・ADR-010）

```
【書誌】リーダブルコード   ISBN: 978-4-87311-565-8   ← ISBN は書誌に1つだけ（重複しない）
   ├─【所蔵 #BC0001】本館3F     状態: 在架      ← 所蔵はバーコードを持つ／ISBN は持たない
   ├─【所蔵 #BC0002】本館3F     状態: 貸出中
   └─【所蔵 #BC0003】理工2F     状態: 在架
```

「変わるもの（場所・状態・どの1冊か）は所蔵へ、変わらないもの（作品の情報・ISBN）は書誌へ」。

### 書誌（Bibliography・全館共有。ISBN でテナント内一意）

- **識別子**: ISBN（任意）/ ISSN（雑誌用）/ JP番号（全国書誌番号）/ NDL 書誌URL
- **タイトル**: タイトル / タイトル読み（ヨミ）/ 別書名（任意） ※副題はタイトルに含める
- **著者**: 著者（複数可・役割 著/編/訳）/ 著者読み（任意）
- **出版・形態**: 出版社 / 出版地 / 出版年 / 版 / ページ数 / 大きさ / 装丁 / シリーズ名 / 言語
- **分類・主題**: NDC8 / NDC9 / NDC10 / NDLC / 自館分類（任意）/ **件名（複数可・主題/タグに相当）** / **資料種別（図書・雑誌・AV。必須）**
- **価格・表示**: 定価 / 書影URL（外部API取得、無ければ手動）/ 内容紹介
- **その他**: 注記・備考

### 所蔵（Item・物理1冊・キャンパス単位。1書誌に N 件ぶら下がる）

- **識別**: 資産バーコード（テナント内一意・自動採番 or スキャン）/ 登録番号（台帳用・バーコードと別運用も可）
- **請求記号**（構成要素を**個別フィールドで保存**し、表示ラベルは組み立て＝導出）: 別置記号（例 R=参考）/ 分類番号（例 007.64・多くは NDC）/ 著者記号（例 ナ）/ 巻冊記号（例 3） 　→ 表示例 `R 007.64/ナ/3`
- **巻次・巻号**: 多巻もの・雑誌の号（例 上巻 / Vol.3 / 2025年4月号）
- **配置**: 所属キャンパス / 配架場所（書架）
- **貸出区分**: 貸出可 / 禁帯出（館内のみ）
- **受入情報**: 受入方法（購入 / 寄贈 / 移管）/ 受入年度 / 受入日時 / 購入価格 / 購入先 / 予算区分（研究費・校費 等）
- **状態**（イベントから導出。ADR-009）: `在架` / `貸出中` / `予約取置` / `配送中` / `紛失` / `破損`（補修・製本中）/ `除籍` ※`返送中` は Q-005
- **その他**: 備考

在庫・可用性は所蔵の集計で表す（(書誌, キャンパス) 単位。→ EP-005）。貸出・予約・配送は所蔵単位（→ EP-003 / EP-004 / EP-005）。

## ユーザーストーリー

### US-001: ISBN による蔵書登録

- **As a** 司書
- **I want** ISBN をスキャン/入力すると書名・著者・ページ数などの書誌が自動で取り込まれる
- **So that** 手入力の負担を減らせる

受け入れ条件:

- [ ] ISBN を入力、またはバーコードスキャンで受け付ける
- [ ] ISBN から国立国会図書館 API で書誌を取得し、フォームにプリフィルする（→ EP-007 US-020）
- [ ] 取得失敗（不通・該当なし）時は手動入力にフォールバックできる
- [ ] 既存の同一 ISBN がある場合は新規作成せず「所蔵追加」へ誘導する
- [ ] 登録に続けて所蔵（キャンパス・配架場所・バーコード・冊数）を登録できる
- [ ] ISBN を持たない資料（雑誌・寄贈・自作冊子等）も ISBN 任意で登録できる
- [ ] CSV 等で複数の蔵書を一括登録できる（導入初期の大量登録用）
- [ ] 登録した所蔵の資産バーコード・背ラベル（請求記号）を印刷できる

### US-002: 蔵書の編集・除籍

- **As a** 司書
- **I want** 蔵書情報の編集と、不要になった蔵書の除籍ができる
- **So that** 蔵書を最新に保てる

受け入れ条件:

- [ ] 書誌情報（タイトル・著者・分類 等）を編集できる
- [ ] 所蔵の配架場所・所属キャンパスを編集できる
- [ ] 所蔵を**除籍状態**にできる（物理削除しない）
- [ ] `貸出中` / `予約取置` / `配送中` の所蔵は除籍できない
- [ ] 編集対象を探すための一覧・検索ができる（タイトル/著者/ISBN/分類/キャンパス/状態）

### US-003: 蔵書詳細の閲覧

- **As a** 司書
- **I want** 蔵書ごとの ISBN・所蔵（配架場所・状態）・登録日・貸出履歴を確認できる
- **So that** 蔵書の状態を把握できる

受け入れ条件:

- [ ] 書誌情報と、紐づく所蔵の一覧（バーコード・キャンパス・配架場所・状態）を表示する
- [ ] 所蔵ごと／書誌集計の貸出履歴を表示する
- [ ] 在庫数・貸出中数をキャンパス別に集計表示する

## 業務ルール

- ISBN は書誌単位で**テナント内一意**。所蔵バーコードも**テナント内一意**。
- 除籍は状態遷移で表し、**物理削除しない**（履歴・参照整合の保持。ADR-009）。
- 書誌は、有効な所蔵（除籍以外）が存在する間は削除しない。全所蔵が除籍/0件になった書誌はアーカイブ扱い（一覧の既定から除外）。
- 同一 ISBN の再登録は所蔵追加として扱う（書誌を重複させない）。
- **権限**: 司書は書誌を全館で閲覧・編集できる。所蔵は**自館分を管理**（他館の所蔵は閲覧のみ。配送・返送時のみ例外）。
- **監査**: 書誌の作成・編集・除籍などの変更は、**実行した司書アカウント・所属キャンパス・日時を履歴として記録**する（ADR-009 のイベントで表現）。
- **貸出区分**: 所蔵は貸出区分（貸出可 / 禁帯出=館内のみ 等）を持ち、`禁帯出` は貸出不可（適用は EP-003）。
- **資料種別**: 書誌は資料種別（図書 / 雑誌 / AV 等）を持つ。雑誌など ISBN 無しの資料もこれで区別できる。

## 制約 / 非機能要件

- NDL 連携は腐敗防止層で隔離し、不通時は手動入力に退避してコア処理を止めない（ADR-003）。
- バーコード入力はハンディスキャナ（キーボード入力エミュレーション）を想定。
- 全データはテナントscope（`tenant_id`。ADR-002）。
