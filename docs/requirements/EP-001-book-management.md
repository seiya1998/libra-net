# EP-001: 蔵書管理

## 概要

司書（管理画面）が蔵書を登録・編集・削除し、蔵書ごとの詳細情報を管理する。登録時は ISBN から書誌を自動取得して職員の負担を減らす。

## ユーザーストーリー

### US-001: ISBN による蔵書登録

- **As a** 司書
- **I want** ISBN をスキャン/入力すると書名・著者・ページ数などの書誌が自動で取り込まれる
- **So that** 手入力の負担を減らせる

受け入れ条件:

- [ ] ISBN から国立国会図書館 API で書誌を取得（→ EP-007）
- [ ] 取得失敗時は手動入力にフォールバックできる

### US-002: 蔵書の編集・削除

- **As a** 司書
- **I want** 蔵書情報の編集・削除ができる
- **So that** 蔵書を最新に保てる

### US-003: 蔵書詳細の閲覧

- **As a** 司書
- **I want** 蔵書ごとの ISBN・保管場所・登録日・貸出履歴を確認できる
- **So that** 蔵書の状態を把握できる
