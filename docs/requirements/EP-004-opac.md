# EP-004: OPAC（利用者向け）

## 概要

学生・教職員・一般が **スマホ/PC** で利用する蔵書検索・予約・貸出状況確認のシステム。主にモバイル利用を想定。

## ユーザーストーリー

### US-010: 蔵書検索

- **As a** 利用者
- **I want** 蔵書を検索できる
- **So that** 読みたい本を探せる

### US-011: 予約・予約待ち人数の確認

- **As a** 利用者
- **I want** 本を予約し、予約の待ち人数を確認できる
- **So that** 入手の見込みが分かる

### US-012: 貸出状況・履歴の確認

- **As a** 利用者
- **I want** 現在の貸出状況（返却期限を含む）と貸出履歴を確認できる
- **So that** 自分の利用状況を把握できる

### US-013: 貸出期間の延長

- **As a** 利用者
- **I want** 貸出期間を延長できる（例: 2週間）
- **So that** 返却期限を延ばせる

### US-014: お気に入り登録

- **As a** 利用者
- **I want** 本をお気に入り登録できる
- **So that** 後で見返せる

## 関連機能（詳細化時に取り込み）

- **電子図書カード表示**: OPAC ログイン後にバーコードを表示し、カウンターのスキャナにかざす（一般利用者中心。学生/教職員は学生証併用可）。発行は EP-002 F-06（印刷なし・電子のみ）。Figma O20 相当。
- **マイ本棚**: 貸出中 / 予約中 / お気に入り / 履歴 のタブ。
- **検索**: フリーワード＋絞り込み（在庫あり / 和書 / 出版年 等）・並び替え・カード/リスト表示・おすすめ/新着。
- **予約・配送**: 書籍詳細から予約（予約待ち人数・受取期限）・別キャンパス配送依頼（EP-005）。
- **通知**: 通知履歴・通知設定（返却期限 / 予約 / お知らせ。メール / プッシュ / カレンダー連携。EP-007）。
- **アカウント設定（アクセシビリティ）**: フォントサイズ・ふりがな・言語・ダークモード・公開氏名・履歴保存期間（アクセシビリティ NFR）。
- **ヘルプ / 司書チャット**: ヘルプ（動画・カテゴリ）、司書チャット（EP-018 バックログ）。

## 制約 / 非機能要件

- モバイル前提の UX。公開ページのため SEO・初期表示速度を重視（`.claude/rules/opac/` 参照）。
