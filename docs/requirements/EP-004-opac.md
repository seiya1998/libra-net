# EP-004: OPAC（利用者向け）

## 概要

学生・教職員・一般が **スマホ/PC** で利用する蔵書検索・予約・貸出状況確認のシステム。主にモバイル利用を想定。

## ユーザーストーリー

### US-010: 蔵書検索

- **As a** 利用者
- **I want** 蔵書を検索できる
- **So that** 読みたい本を探せる

### US-011: 予約・予約待ち人数の確認

- **As a** 利用者
- **I want** 本を予約し、予約の待ち人数を確認できる
- **So that** 入手の見込みが分かる

### US-012: 貸出状況・履歴の確認

- **As a** 利用者
- **I want** 現在の貸出状況（返却期限を含む）と貸出履歴を確認できる
- **So that** 自分の利用状況を把握できる

### US-013: 貸出期間の延長

- **As a** 利用者
- **I want** 貸出期間を延長できる（例: 2週間）
- **So that** 返却期限を延ばせる

### US-014: お気に入り登録

- **As a** 利用者
- **I want** 本をお気に入り登録できる
- **So that** 後で見返せる

## 制約 / 非機能要件

- モバイル前提の UX。公開ページのため SEO・初期表示速度を重視（`.claude/rules/opac/` 参照）。
