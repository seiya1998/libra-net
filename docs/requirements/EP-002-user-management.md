# EP-002: 利用者管理

## 概要

利用者は **学生 / 教職員 / 一般** の3層。学生・教職員は固有ID（学籍番号・従業員ID）で突合。一般はバーコード付き図書カードの一意番号で一元管理し、登録は来館して行う（セキュリティ確保）。

## ユーザーストーリー

### US-004: 利用者一覧・詳細の確認

- **As a** 司書
- **I want** 利用者一覧と各利用者の詳細（貸出状況など）を確認できる
- **So that** 利用者を管理できる

### US-005: 学生・教職員の ID 突合

- **As a** 司書
- **I want** 学籍番号 / 従業員ID で利用者アカウントを突合できる
- **So that** 大学の構成員を正しく識別できる

### US-006: 一般利用者の登録（来館・図書カード）

- **As a** 一般利用者
- **I want** 来館して登録し、バーコード付き図書カードの番号で一元管理される
- **So that** 誰でも登録できてしまうのを防ぎつつ利用できる

## 制約 / 非機能要件

- 一般利用者の登録は来館手続きを前提（不正登録防止）。
- 図書カード番号は一意。
