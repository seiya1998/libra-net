# 要件定義

エピック単位で `EP-NNN-{domain}.md` に分割する。新規エピックは `_template.md` を複製して作成。

- ストーリー（`US-NNN`）は**全体通し連番**。エピック内でリセットしない。
- 非機能要件・スコープ外・横断事項は本 README に記載する。
- spec/ と 1:1 でミラーする（同名ファイル）。

## 非機能要件 / 横断事項

- **組織モデル**: テナント = 大学（OPAC・サブドメインは大学に1つ）。1大学に複数キャンパス、各キャンパスに図書館と司書（管理画面ユーザー）。**書誌は大学で共有・所蔵はキャンパス単位**。司書は自館の所蔵を管理し、書誌は全館で共有・編集可（ADR-010。詳細は EP-002 / EP-005 / EP-006）。
- **マルチテナント**: 共有DB＋行レベル `tenant_id`、分離はリポジトリ＋型＋テストで強制（ADR-002）。
- **OPAC**: モバイル前提・公開ページゆえ SEO/初期表示速度を重視。
- **外部連携**: 腐敗防止層で隔離、不通時もコア処理を止めない（ADR-003）。
- **認証**: 独自認証（学籍番号/従業員ID/図書カード番号で突合、SSO なし）（ADR-007）。
