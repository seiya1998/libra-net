# EP-008: お知らせ・ダッシュボード

## 概要

OPAC に掲載するお知らせの作成・編集と、管理画面トップでの概要表示。

## ユーザーストーリー

### US-023: お知らせの作成・編集

- **As a** 司書
- **I want** OPAC に掲載するお知らせ（おすすめの本、閉館時間の変更など）を作成・編集できる
- **So that** 利用者に情報を伝えられる

### US-024: 管理ダッシュボード概要

- **As a** 司書
- **I want** 管理トップで在庫数・貸出中冊数などの概要を確認できる
- **So that** 図書館の状況を一目で把握できる

## 関連機能（詳細化時に取り込み）

- **お知らせ作成（詳細）**: 公開タイミング（今すぐ / 予約）・公開期間・対象（全利用者 / 種別）・**公開後5分以内は撤回可**・閲覧数。アクセシビリティ: 読解レベル調整・**画像の代替テキスト必須**・OPAC プレビュー・スクリーンリーダー読み上げ（アクセシビリティ NFR）。
- **ダッシュボード KPI**: 本日の貸出 / 延滞中（要対応）/ 本日返却予定（遅延見込）/ 予約順番到来 / システムお知らせ。
- **通知（OPAC・EP-004/007 連携）**: 通知履歴・通知設定（メール / プッシュ / ブラウザ / カレンダー連携）。
- **統計・レポート**（文科省 学術情報基盤実態調査含む）は本エピックの拡張（バックログ）。
