# EP-008: お知らせ・ダッシュボード

## 概要

OPAC に掲載するお知らせの作成・編集と、管理画面トップでの概要表示。

## ユーザーストーリー

### US-023: お知らせの作成・編集

- **As a** 司書
- **I want** OPAC に掲載するお知らせ（おすすめの本、閉館時間の変更など）を作成・編集できる
- **So that** 利用者に情報を伝えられる

### US-024: 管理ダッシュボード概要

- **As a** 司書
- **I want** 管理トップで在庫数・貸出中冊数などの概要を確認できる
- **So that** 図書館の状況を一目で把握できる
