# EP-003: 貸出・返却・延滞管理

## 概要

司書（管理画面）が学生証・本のバーコードをスキャンして貸出 / 返却を行い、延滞を管理する。貸出ルール（上限・期間・延長・予約上限）は **利用者種別ごと**に定義し、EP-002 の利用者種別マスタに紐づける。状態はイベント（貸出 / 返却 / 延長 / 予約 / 督促）から導出し、参照は所蔵・利用者の `current_status` で行う（ADR-009）。

## 前提モデル

- **イベント**（append-only・ADR-009）: 貸出 `e_loans` / 返却 `e_returns` / 延長 `e_renewals` / 予約 `e_reservations` / 督促 `e_reminders`
- **所蔵の `current_status`**: 整理中 / 在架 / 貸出中 / 予約取置 / 配送中 / 返送中 / 紛失 / 破損 / 除籍
- 導出: 貸出中＝返却のない貸出、延滞＝貸出中かつ返却期限超過。
- **カレンダー設定（テナント/キャンパスごと）**: 長期貸出期間（冬休み・夏休み 等）／休館日（定休・長期休暇・臨時）。返却期限の算出に用いる。

### 貸出ルール（利用者種別ごと・初期値。変更可。EP-002 種別マスタに紐づく）

| 種別 | 貸出上限 | 貸出期間 | 延長 | 予約上限 |
|---|---|---|---|---|
| 学生 | 10冊 | 14日 | 1回(+14日) | 5件 |
| 教員 | 30冊 | 90日 | 2回 | 10件 |
| 事務 | 10冊 | 30日 | 1回 | 5件 |
| 一般 | 5冊 | 14日 | 不可 | 3件 |

## ユーザーストーリー

### US-007: 貸出（スキャン）

- **As a** 司書
- **I want** 学生証（利用者）と本のバーコードをスキャンして貸出を完了できる
- **So that** 貸出処理を素早く行える

受け入れ条件:

- [ ] 利用者の識別子と本のバーコードをスキャンして貸出できる
- [ ] 貸出時にルール判定する（**貸出上限超過 / 禁帯出 / 利用者が停止中** は不可）
- [ ] 返却期限＝貸出日＋種別の貸出期間 を自動算出する
- [ ] 長期貸出期間（休暇）中の貸出は、対象種別（学生・教員）の返却期限を**休み明けの設定日**にする
- [ ] 返却期限が**休館日に当たる場合は翌開館日へ繰り下げる**（全種別）
- [ ] 予約取置中の所蔵は、その予約者にのみ貸出できる

### US-008: 返却

- **As a** 司書
- **I want** 返却処理ができる
- **So that** 蔵書の在庫を最新に保てる

受け入れ条件:

- [ ] 本のバーコードをスキャンして返却できる
- [ ] **どのキャンパスでも返却できる**。借りた館と異なれば**返送**する（元館へ。所蔵 `current_status` = 返送中 → 元館で在架）
- [ ] 返却時に予約待ちがあれば次の予約者へ**取置**する

### US-009: 延滞管理

- **As a** 司書
- **I want** 延滞中の利用者・蔵書を一覧で管理できる
- **So that** 督促などの対応ができる

受け入れ条件:

- [ ] 延滞（返却期限超過）を一覧で確認できる
- [ ] 督促（メール等）を送れる・記録する
- [ ] 延滞中の利用者は**新規貸出を停止**する（延滞金はなし）

## 業務ルール

- **貸出可否**: 貸出上限超過 / 禁帯出（貸出区分）/ 利用者 `current_status` = 停止 → 不可。返却期限＝貸出日＋種別の貸出期間。
- **延長**: 延長回数の上限内 **かつ 予約者がいない** 場合のみ可（司書 / 利用者 = EP-004）。延長で返却期限を延ばす。
- **延滞**: 返却期限超過で延滞。督促を送る。延滞中は新規貸出停止。**返却で停止解除**（追加ペナルティ期間なし・延滞金なし）。
- **返却**: どのキャンパスでも可。他館の所蔵は**返送**（Q-005 採用。状態 返送中）。
- **予約**: 在庫が全て貸出中の書誌に予約（受付は EP-004）。返却時に予約先頭へ取置。**取置期限 7日**（過ぎたら次の予約者へ）。割当ロジックは Q-006。
- **状態**: 参照は `current_status`、真実はイベント（追記時に同一 Tx で更新。ADR-009）。
- スタッフは相互利用で**他館の利用者**の貸出も可（ホーム館に依らない）。
- **長期貸出（休暇）**: 長期貸出期間内の貸出は、**学生・教員**の返却期限を休み明けの設定日にする。**休暇前から借りている分も一括で延長**する。一般・事務は対象外（通常期間）。
- **休館日カレンダー**: 返却期限が休館日に当たる場合は**翌開館日へ繰り下げる**（全種別。閉館中に延滞させない）。
- **リコール（recall）**: 予約が入った貸出中の所蔵は、返却期限を繰り上げて利用者に早期返却を要請（督促）できる。
- **弁償**: 紛失・破損の所蔵は弁償処理する（弁償額は定価ベース、定額・上限も設定可。Q-020）。弁償完了で除籍（必要なら同一書誌へ補充）。
- **督促一括送信**: 延滞者へまとめて督促。送信後 **5分の撤回ウィンドウ**（ジョブ ID で撤回可）。送信・撤回は監査記録（ADR-011）。
- **緊急延長一括処理**: 災害・停電・臨時休館等で全延滞期限を一括延長（**管理者承認＋実行理由＋監査ログ必須**。影響範囲をプレビュー）。
- **返却モード**: 通常モードのほか、混雑時の**連射バッファモード**（連続スキャン→積み上げ→一括確定。要対応＝予約者あり / 破損 / 他テナント / 不明 ISBN を仕分け）。短時間 Undo（誤返却取消）可。

## 制約 / 非機能要件

- 貸出 / 返却はハンディスキャナ前提・高速処理（カウンター混雑時）。
- イベントは append-only・監査（ADR-009）。
- 全データはテナントscope（`tenant_id`。ADR-002）。
