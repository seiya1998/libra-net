# EP-003: 貸出・返却・延滞管理

## 概要

司書（管理画面）が学生証・本のバーコードをスキャンして貸出/返却を行い、延滞を管理する。

## ユーザーストーリー

### US-007: 貸出（スキャン）

- **As a** 司書
- **I want** 学生証（利用者）と本のバーコードをスキャンして貸出を完了できる
- **So that** 貸出処理を素早く行える

### US-008: 返却

- **As a** 司書
- **I want** 返却処理ができる
- **So that** 蔵書の在庫を最新に保てる

### US-009: 延滞管理

- **As a** 司書
- **I want** 延滞中の利用者・蔵書を一覧で管理できる
- **So that** 督促などの対応ができる
