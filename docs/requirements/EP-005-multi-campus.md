# EP-005: 複数キャンパス・拠点間在庫・配送

## 概要

大学が複数キャンパス/拠点を持つ場合に、拠点間の在庫確認と配送を扱う。

## ユーザーストーリー

### US-015: 拠点間の在庫確認・表示

- **As a** 利用者
- **I want** 複数キャンパス・拠点の在庫を確認・表示できる
- **So that** どの拠点に在庫があるか分かる

### US-016: 別キャンパスへの配送依頼・受取設定

- **As a** 利用者
- **I want** 別キャンパスへの本の配送を依頼し、受け取り先を設定できる
- **So that** 所属外キャンパスの本も受け取れる

## 制約 / 非機能要件

- 在庫・可用性は (蔵書, キャンパス) 単位。テナント内でキャンポスを横断（テナント越境はしない）。
