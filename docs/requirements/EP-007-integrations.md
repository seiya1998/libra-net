# EP-007: 外部連携

## 概要

既存サービスとの差別化のため、外部システムと連携する。国立国会図書館 API（書誌取得）、Google カレンダー（通知）、AI 活用。

## ユーザーストーリー

### US-020: 国立国会図書館 API による書誌取得

- **As a** 司書
- **I want** ISBN から国立国会図書館 API で書誌（タイトル・著者・ページ数等）を取得できる（→ EP-001 US-001）
- **So that** 登録の手間を減らせる

### US-021: Google カレンダー連携

- **As a** 利用者
- **I want** 返却日がカレンダーに自動設定され通知が届く／予約の順番が来たら通知される
- **So that** 返却忘れや機会損失を防げる

### US-022: AI 活用

- **As a** 利用者/運営者
- **I want** AI を活用した付加機能（おすすめ等）を利用できる
- **So that** 体験と独自性を高められる（将来検討）

## 制約 / 非機能要件

- 外部連携は腐敗防止層（ポート＋アダプタ）で隔離（→ ADR-003）。NDL 不通時は手動登録に退避しコア処理を止めない。
