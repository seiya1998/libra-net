# 情報源マップ

| docs | 情報源 |
|---|---|
| `schema.md` | `apps/server/src/db/schema.ts`（Drizzle 定義）, `apps/server/docs/openapi-for-admin.yaml` |
| `api.md` | `apps/server/src/**/_handlers.ts`, `apps/server/src/**/schema.ts`, `apps/server/docs/openapi-for-admin.yaml` |
| `architecture.md` | `.claude/rules/server/architecture.md`, `apps/admin/src/routes`, `apps/admin/src/features` |
| `glossary.md` | `docs/spec/EP-*.md`, `apps/server/docs/openapi-for-admin.yaml` |

> server 未実装の現状では、実体のある情報源は主に admin（`apps/admin/src`）と OpenAPI スキーマ。
