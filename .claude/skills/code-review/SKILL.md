`code-reviewer` エージェントを起動してレビューを実行する。

エージェントの結果を以下の形式で表示する（該当コード・修正コード例は省略）。

採番ルール: **MUST** 全カテゴリ通しで連番（Critical #1,#2 → Warning #3,#4 → Info #5）。**NEVER** カテゴリごとにリセットしない。

```
Critical (N件)

#: 1
場所: /absolute/path/to/file.ts:line
影響: 1行で何が起きるか
修正案: 1行でどう直すか
────────────────────────────────────────
#: 2
...

Warning (N件)

#: 3
場所: ...
影響: ...
修正案: ...
────────────────────────────────────────

Info (N件)

#: 4
場所: ...
影響: ...
修正案: ...
```
