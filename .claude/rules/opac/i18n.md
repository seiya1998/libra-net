# i18n ルール（next-intl）

## 方針

- **YOU MUST**: i18n は **next-intl** を使う。ロケールは `[locale]` セグメント（`/ja`, `/en` …）でルーティングする。
- **YOU MUST**: メッセージは `messages/{locale}.json` 等で管理し、キーは機能単位で名前空間化する。
- **YOU MUST**: 文言をコードに直書きしない（必ずメッセージキー経由）。最低限 日本語/英語に対応。
- 翻訳はできるだけ **Server Component 側**で行い、クライアントへ送るメッセージを最小化する（バンドル削減・`security.md` の境界方針と整合）。

## サーバー / クライアントでの使い分け

- Server Component: `getTranslations`
- Client Component: `useTranslations`（`NextIntlClientProvider` 配下）

## 最小例（形のみ）

```typescript
// Server Component
const t = await getTranslations('search');
return <h1>{t('title')}</h1>;
```
